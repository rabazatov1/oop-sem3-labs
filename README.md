# Лабораторная работа 1: матрицы на динамической памяти

Консольная программа с текстовым меню, которая работает с динамической матрицей `int**` и выполняет над ней операции. Вариант 17: максимумы строк и минимумы столбцов.

---

## О проекте

Лабораторная работа 1 по ООП двумерные массивы, матрицы `int**`.

Вся логика оформлена как библиотека функций, которые сами ничего не вводят и не выводят, а принимают данные параметрами и возвращают результат. Меню, чтение чисел и сообщения живут отдельно, в `main.cpp`. Благодаря этому одни и те же функции вызываются и из программы, и из автоматических тестов.

Алгоритм варианта 17:

- `matrix_row_max` возвращает массив максимумов каждой строки;
- `matrix_col_min` возвращает массив минимумов каждого столбца.

Пример: для матрицы `[[3, 1, 4], [5, 2, 0]]` максимумы строк `{4, 5}`, минимумы столбцов `{3, 1, 0}`.

## Меню программы

```
1. Создать матрицу
2. Заполнить значением
3. Напечатать
4. Алгоритм варианта
5. Задать элемент
0. Выход
```

| Пункт | Что происходит |
|---|---|
| 1 | Запрашивает число строк (1–1000) и столбцов (0–1000), освобождает старую матрицу и создаёт новую (заполнена нулями) |
| 2 | Запрашивает число и записывает его во все ячейки |
| 3 | Печатает матрицу построчно |
| 4 | Печатает максимумы строк и минимумы столбцов |
| 5 | Запрашивает строку, столбец (нумерация с нуля) и значение, записывает его в одну ячейку |
| 0 | Освобождает память и завершает программу |

Некорректный ввод (буквы, отрицательные размеры, индексы вне матрицы) не роняет программу: выводится сообщение, и меню показывается снова. Если матрица не создана, пункты 2, 3, 4 и 5 сообщают об этом.

Пример: чтобы получить матрицу `[[3, 1, 4], [5, 2, 0]]`, создайте матрицу 2×3 (пункт 1) и шесть раз выберите пункт 5, вводя `0 0 3`, `0 1 1`, `0 2 4`, `1 0 5`, `1 1 2`, `1 2 0`. Пункт 4 выведет максимумы `4 5` и минимумы `3 1 0`.

## Функции библиотеки

Определены в `include/lab1/matrix_ops.hpp`, пространство имён `lab1`.

| Функция | Назначение |
|---|---|
| `int** matrix_create(rows, cols)` | Создаёт матрицу, все ячейки равны 0. При `rows == 0` возвращает `nullptr` |
| `void matrix_delete(m, rows)` | Освобождает сначала все строки, затем массив указателей. Для `nullptr` ничего не делает |
| `void matrix_fill(m, rows, cols, value)` | Записывает `value` во все ячейки |
| `void matrix_print(m, rows, cols)` | Печатает матрицу в `std::cout` |
| `int* matrix_row_max(m, rows, cols)` | Массив длины `rows` с максимумом каждой строки |
| `int* matrix_col_min(m, rows, cols)` | Массив длины `cols` с минимумом каждого столбца |

Контракты:

- Если матрица пуста (`nullptr`, `rows == 0` или `cols == 0`), `matrix_row_max` и `matrix_col_min` возвращают `nullptr`.
- Результат этих двух функций выделен через `new[]`. Освобождает его вызывающий код через `delete[]`.
- `matrix_delete` не обнуляет указатель вызывающего (сигнатура задана методичкой), это делает `main`.


CMake описывает три цели:

| Цель | Что собирает |
|---|---|
| `lab1_lib` | статическая библиотека из `matrix_ops.cpp` |
| `lab1_main` | программа: `main.cpp` + `lab1_lib` |
| `tests` | тесты: `matrix_ops_test.cpp` + `lab1_lib` + GoogleTest |

## Тесты

12 тестов в двух наборах:

- `MatrixOpsTest` (9): создание, заполнение, контрольный пример из методички, одна ячейка, отрицательные числа, `nullptr` в `delete` и `print`;
- `MatrixOpsTest_Fail` (3): ожидаемый отказ без исключения, то есть возврат `nullptr` при нулевых размерах.

Ожидаемые значения заданы константами, а не вычисляются теми же функциями.
